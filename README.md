# DNS Performance Test

A tool for benchmarking DNS server performance across various domain types.

## Features

- Tests DNS resolution performance for various domain types (international, local, invalid, etc.)
- Measures response times and success rates
- Generates comprehensive statistics and reports
- **Compare multiple DNS server results** with colorized performance tables
- Export comparison data to CSV format

## Requirements

- Node.js
- npm

## Installation

1. Clone this repository
2. Install dependencies: `npm install`
3. Make sure the test script is executable: `chmod +x dns_test.js`

## Usage

```bash
# Run the DNS test against a specific DNS server
./dns_test.js 8.8.8.8

# Compare results from multiple DNS servers
./compare_results.js
```

## Test Configuration

Edit `test_suite.yaml` to customize test domains:

```yaml
test_groups:
  international:
    - lemonde.fr
    - bbc.co.uk
  # Add more groups and domains as needed
```

## Output Files

- `dns_results_<server>.csv` - Raw test results in CSV format for each DNS server
- `dns_summary_<server>.txt` - Summary statistics for each test run
- `dns_comparison.csv` - Comparison table of all DNS servers (generated by compare_results.js)

## Comparing Multiple DNS Servers

After running tests against multiple DNS servers, use the comparison tool:

```bash
./compare_results.js
```

### Color-Coded Performance

The comparison table uses colors to highlight performance:
- **🟢 Green**: Best performing values
- **🟡 Yellow**: Moderate performance
- **🔴 Red**: Worst performing values

Colors are applied based on metric type:
- **Lower is better**: Response times, percentiles
- **Higher is better**: Success rates, domains tested

## Notes

This tool was designed and tested to run on macOS. It uses macOS-specific networking commands (`networksetup`, `dscacheutil`) and may not work on other operating systems without modifications.

### Scripts

- **`dns_test.js`** - Main DNS performance testing tool
- **`compare_results.js`** - Comparison tool for analyzing multiple DNS server results
